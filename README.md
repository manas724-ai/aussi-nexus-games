## 🕹️ Three Original Strategy Games

| Game | Genre | Status |
|------|-------|--------|
| [NEXUS STRIKE: Zone Ops](./nexus-strike/) | Tactical Team Strategy Shooter | ✅ Ready |
| [STORM RIDERS: Build & Conquer](./storm-riders/) | Battle Royale Builder Strategy | ✅ Ready |
| [INFERNO RUN: Last Squad](./inferno-run/) | Survival Squad Strategy | ✅ Ready |

All three games are **PWA-installable**, **mobile-first**, and feature:
- Full frontend game engine (HTML5 Canvas / JS)
- Node.js/Express backend with REST API
- WebSocket real-time multiplayer support
- Service Worker offline capability
- Installable PWA manifest
- Leaderboard & session persistence
- Responsive design for all screen sizes

## 🚀 Quick Start (All Games)

```bash
# Clone the repo
git clone https://github.com/manas724-ai/aussi-nexus-games.git
cd aussi-nexus-games

# Run any game
cd nexus-strike && npm install && npm start
cd storm-riders && npm install && npm start
cd inferno-run  && npm install && npm start
```
