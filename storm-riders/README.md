## About
STORM RIDERS is an original battle royale game with building mechanics — last rider standing wins. Harvest materials, build cover, loot weapons, and outlast 40 enemy riders while the storm closes in.

## Features
- 🌍 Massive 5000×5000 world map with procedural terrain
- 🔫 6 original weapons across 4 rarity tiers (Common→Legendary)
- 🏗 Full build system: Walls, Floors, Ramps, Towers (Wood/Brick/Metal)
- ⚡ Dynamic storm system with shrinking ring
- 🎒 3-slot inventory + material harvesting
- 🤖 40 AI enemy bots
- 🌐 WebSocket real-time multiplayer backend
- 📱 PWA installable
- 🏆 Leaderboard with placements & build counts

## Controls
| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Aim & Shoot |
| E | Harvest materials |
| Q | Toggle Build Mode |
| 1/2/3 | Equip weapon slot |
| Click (Build Mode) | Place structure |
| Enter | Send chat |
