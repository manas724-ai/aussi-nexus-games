## About
INFERNO RUN: Last Squad is an original survival squad game featuring 6 unique characters each with special abilities, zone-based survival, squad revive mechanics, and dynamic loot system.

## Features
- 🦸 6 original playable characters with unique abilities
- ⚡ Active ability system with cooldown timers
- 🔫 6 original weapons (RazorFire M4, Venom 9, Thunderbore, BlastPump, etc.)
- 🗺 4000×4000 procedural world map with biome variety
- 🔥 Shrinking fire zone system
- 💊 Squad revive mechanics
- 🎒 Dynamic loot system (weapons, health, armor drops)
- 🤖 30 AI bots with character classes
- 🌐 WebSocket real-time multiplayer backend
- 📱 PWA installable
